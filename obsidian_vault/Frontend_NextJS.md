# Frontend NextJS

Aplicación web ubicada en web/ que proporciona una GUI interactiva e inmersiva.

## Stack
- Next.js 16 (App Router) + React 19 + TypeScript.
- **Visualización**: Recharts para gráficas, Three.js para renderizar la escena 3D del ensamblaje.

Consume el [[Backend_FastAPI]] para visualizar en vivo cómo el [[Motor_Algoritmo_Genetico]] converge.
